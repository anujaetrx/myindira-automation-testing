# IUN-3225 Social Feed Hub & Moderation Management: automated test cases

- **Story:** IUN-3225 "Social Feed Hub & Moderation Management" (rules BR-01 to BR-05)
- **Module:** Admin > Social Feed, screen `/feed`
- **Environment:** QA, `https://app-test.k.indiraiscm.com`, signed in as ADMIN
- **Spec files:** `tests/e2e/IUN3225-SocialFeed/IUN3225-social-feed.spec.ts` (46 tests), `tests/e2e/IUN3225-SocialFeed/IUN3225-social-feed.gap.spec.ts` (8 tests)
- **Summary doc:** `docs/test-cases/social-feed.md`
- **Date:** 2026-11-20
- **Last run (2026-11-20):** all passed (known defects are expected-fail); the gated publish/delete lifecycle test was not run.
- **Test case IDs:** the id already in the test title (TC_SF_nnn, from the team's sheet). Several titles share an id (for example TC_SF_014 has three tests); these are listed as separate rows. The 8 gap-review tests have no id in their title, so they were given `GAP_SF_001` to `GAP_SF_008` in file order.

## Preconditions for the whole file (important)

- All tests run as ADMIN on the shared QA environment. Nothing here changes data on QA.
- **Most write actions are intercepted** (`guardWrites`): Post, react, comment, flag, delete and the tab "mark viewed" call are answered locally and recorded. The test asserts the request the screen SENT (method, path, body), not a server result. Read calls go to the real server.
- Where the data situation cannot exist safely on QA (empty feed, birthdays, community posts, 25 posts), the API response is mocked ("Mocked API").
- Test media (PNG, JPG, WEBP, MP4, PDF) is generated by the test and padded to the size needed.
- Viewport requested 1440x900 (the browser window is in practice 1280x720; locators are text/size based).

## Legend

**Type:** Positive / Negative / Boundary / Known defect (test.fail, expected to fail until the app is fixed) / Gated (real write, not run) / Mocked API (data situation simulated).

**Result:** `Pass` = passed in the last full run; `Known defect (expected fail)` = `test.fail`, green while the defect exists and turns red once the app is fixed; `Gated, not run` = skipped without `ALLOW_FEED_WRITES=true`.
