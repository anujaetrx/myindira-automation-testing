# IUN-3230 Admin Posts Creation & Targeted Broadcasting: automated test cases

- **Story:** IUN-3230 "Admin Posts Creation & Targeted Broadcasting" (rules BR-AP-01 to BR-AP-05, scenarios 1 to 5, story QA cases TC_AP_001 to TC_AP_008)
- **Module:** Admin > Admin Posts (sidebar item "Admin Posts"; real route `/posts`; list API `GET /admin/posts?page=0&size=20`)
- **Environment:** QA, `https://app-test.k.indiraiscm.com`, signed in as ADMIN
- **Spec file:** `tests/e2e/IUN3230-AdminPosts/IUN3230-admin-posts.spec.ts` (77 tests)
- **Summary doc:** `docs/test-cases/admin-posts.md`
- **Date:** 2026-11-20
- **Last run (2026-11-20):** all passed (known defects are expected-fail); the gated real publish + delete lifecycle test was not run.
- **Test case IDs:** the id already in the test title. TC_AP_001 to TC_AP_008 are the story's own cases; TC_AP_009 and up are extra cases. Some titles share an id (TC_AP_001, TC_AP_002 twice; TC_AP_033 and TC_AP_035 are loops); each generated case is its own row.

## Preconditions for the whole file (important)

- All tests run as ADMIN on the shared QA environment. **Nothing is published for real**: publishing notifies real students and employees.
- **Most write actions are intercepted** (`guardWrites`): Publish, Delete and reactions are answered locally and recorded; the test asserts the request the screen SENT (method, path, and the multipart `post` JSON that shows `title`, `body`, `targets`, `category`, `mediaKey`, `mediaType`). Photo/video uploads to cloud storage (a PUT to a pre-signed URL) are blocked by `guardMediaUpload` and only the request is asserted.
- Empty list, error and five-category list are mocked ("Mocked API"); the "new post at the top" test simulates the server.
- Test media (JPG, PNG, WEBP, MP4, PDF, EXE) is generated by the test, padded to the size needed.
- Rows that say "Create Post open" mean: open /posts, click the quick-post box ("What's on your mind") to open the Create Post modal.

## Legend

**Type:** Positive / Negative / Boundary / Known defect (test.fail, expected to fail until the app is fixed) / Gated (real write, not run) / Mocked API.

**Result:** `Pass` = passed in the last full run; `Known defect (expected fail)` = `test.fail`; `Gated, not run` = skipped without `ALLOW_ADMINPOSTS_WRITES=true`.
